## What I'm building

### [AI Commerce OS — Chutney](https://github.com/Ankitajainkuniya/ai-commerce-os)
Multi-tenant SaaS for WhatsApp AI agents. Brands get a ReAct loop agent (Anthropic Claude), BSP billing, embeddable inbox widget, and Postgres RLS so every query is automatically scoped to the authenticated brand.

- **Stack**: Python · FastAPI · SQLAlchemy · PostgreSQL · Anthropic SDK · React · TypeScript
- **AI**: Claude tool-use loop — knowledge base search, read-only SQL, HTTP requests, A2A JSON-RPC, human handoff
- **Auth**: API-key + Postgres `set_config` row-level security
- **Deploy**: Railway (backend) · Vercel (frontend)

### [Mela](https://github.com/Ankitajainkuniya/ai-commerce-os) — Exhibition & Event Discovery
Mobile-first platform (React Native + Expo) connecting organisers, brands, sponsors, and service providers for India's exhibition ecosystem.

### [AP2 Shopping Concierge](https://github.com/Ankitajainkuniya/AP2-shopping-concierge)
Conversational shopping agent with product recommendations and cart management.

### [Agentic AI Platform](https://github.com/Ankitajainkuniya/agentic-ai-platform)
Experiments in multi-agent orchestration, tool use, and ReAct patterns.
